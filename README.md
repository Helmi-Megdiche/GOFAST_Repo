# GOFAST

Starter files for the GOFAST repository.

1. Create an empty folder `fastgo`, unzip this kit into it, then `git init` and make a first commit.
2. Push it to the team's private repository so the other two engineers get the same `CLAUDE.md`.
3. Open Claude Code in the folder and run the prompts in `docs/prompts/web-ui.md`, one at a time.

| File | What it is |
|---|---|
| `CLAUDE.md` | Rules every engineer's Claude Code reads automatically |
| `docs/spec/fonctionnalites.md` | Feature list with IDs and lots |
| `docs/ui/` | The 152 mockup screens, tokens, translations and logos |
| `docs/prompts/web-ui.md` | The four prompts to build the web UI |
